# groupctl v0.3.3

MIT-licensed Python CLI distribution for human and AI collaboration through Git.
Copyright (c) 2026 yyyunx. Existing CLI commands, protocol 0.1, and packaged
Codex/Claude/Gemini Agent Skills are preserved. No AI API key is required.

## Install without cloning tool source

With Git, Python 3.10+ and pipx installed:

```text
pipx install "https://github.com/yyyunx/groupctl-ai-collaboration/releases/download/v0.3.3/groupctl-0.3.3-py3-none-any.whl"
groupctl --version
groupctl agent-setup --target /path/to/team --dry-run
groupctl agent-setup --target /path/to/team
groupctl --repo /path/to/team doctor
```

Agent setup preserves existing settings by default; explicit replacement requires
--overwrite --confirm and creates backups. README covers Windows/Linux, venv installs,
first-team setup, updates, removal and troubleshooting. This release is distributed
through GitHub; it has not been uploaded to PyPI.
