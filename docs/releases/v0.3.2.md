# groupctl v0.3.2 — Distribution preparation

This is a **draft for review**. The owner has not yet approved source/contributor
rights or selected a license. Do not publish this release or upload to PyPI until
that review and explicit owner approval are complete. No MIT or other license grant
is implied by these artifacts.

The distribution now includes the CLI and complete Codex/Claude/Gemini instructions
and skills. Students will be able to install the wheel without cloning tool source,
then run:

```text
groupctl --version
groupctl agent-setup --target /path/to/team --dry-run
groupctl agent-setup --target /path/to/team
groupctl --repo /path/to/team doctor
```

Existing configuration is preserved by default. Conflicts stop all writes;
replacement requires `--overwrite --confirm` and creates backups. No AI API key
is required by groupctl. Existing collaboration commands and protocol 0.1 remain.

Assets: `groupctl-0.3.2-py3-none-any.whl`, `groupctl-0.3.2.tar.gz`, `SHA256SUMS`,
`RELEASE-PROVENANCE.json`. The provenance identifies the exact tag/commit and
Actions run. The draft workflow attaches artifacts only after full Ubuntu/Windows
tests, the existing fifteen-step acceptance and fresh wheel/sdist installations
on Python 3.10 and 3.13 all succeed. Main CI alone is insufficient.
